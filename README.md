# Gab Hermoso — The Edit Room

Static video editor portfolio with an interactive collection viewer, category filters, 22 original library links, the historical Facebook archive, and a BIR seal link that opens the supplied image in a new tab.

## Open locally
Extract the entire ZIP. Open index.html inside the extracted gab-hermoso-portfolio folder. Keep styles.css, script.js, and assets beside it. No installation or build step is needed. Internet access loads Google Fonts and opens the linked videos; fallback fonts work offline.

## Upload to GitHub
1. Upload all contents of gab-hermoso-portfolio to your repository root, including assets, .github, and .nojekyll. Do not upload only index.html or the ZIP.
2. Use a main branch. If your branch has a different name, update .github/workflows/deploy.yml.
3. In Settings → Pages → Source, select GitHub Actions.
4. In Actions → Deploy portfolio to GitHub Pages, choose Run workflow. Future pushes to main deploy automatically.

Alternatively, select Deploy from a branch, main, / (root) in Pages settings instead of using the workflow. Use only one method.

## Edit
- index.html: name, profile, and layout.
- styles.css: palette, typography, responsive layouts.
- script.js: collection descriptions and video URLs.
- assets/bir-registration-seal.png: supplied seal image.

All original 23 unique PDF URLs are retained. Channel links include work by other editors; artwork is illustrative, not video footage. Facebook may require sign-in. No contact email was supplied; the historical Facebook archive is labeled inactive. No video is downloaded or rehosted.
